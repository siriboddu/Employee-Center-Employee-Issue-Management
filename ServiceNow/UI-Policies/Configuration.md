# UI Policies – Configuration

## Overview

UI Policies were configured in the Employee Center application to control the behavior of fields on the Employee Raises Issue form.

## Purpose

The UI Policies help enforce business rules and improve the consistency of employee issue submissions.

## Functions

The configured UI Policies can be used to control:

- Field visibility
- Field mandatory status
- Field read-only status
- Form behavior based on selected values

## Benefits

UI Policies help:

- Reduce incomplete submissions.
- Improve data consistency.
- Guide employees while entering issue information.
- Enforce business requirements at the form level.

## Validation

The UI Policy behavior was tested during the Employee Issue submission process to verify that the configured field restrictions and behavior were applied as expected.
